# Odin Recipes

## Description
This project is part of The Odin Project curriculum. It is a basic recipe website built to practice fundamental web development workflows.

## Demonstrated Skills
By completing this project, I will have demonstrated my ability to:
* Manage local and remote codebase synchronization using Git and GitHub.
* Structure plain text documents into valid HTML web pages.
* Utilize fundamental structural HTML tags including headings, paragraphs, lists, and images.
* Link multiple local webpages together using relative file paths.
